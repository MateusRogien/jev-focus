API key & provider

Jev Focus has no backend. Classification requests go from this browser straight to the provider you pick, using your own key.

Provider

Advanced: base URL and model

Profiles

A profile is the list of categories Jev sorts each video into. Videos in allowed categories stay; everything else is hidden. Presets are read-only. Duplicate one to edit it.

Surfaces

Where filtering applies. The video you're watching is never touched.

Strictness & failure

Strictness

When Jev is unavailable

No key, bad key, rate limit, offline, or a response slower than 3 s.

Floating counter

Channel lists

Checked locally before Jev is asked, so listed channels never cost an API call. One channel name or @handle per line. Block wins over allow.

Cache

— videos cached

Jev's answer for each video is kept for 7 days (at most 5,000), per profile. It holds video ids and category probabilities, nothing else.

Privacy

What is sent

For each video card on a surface you've turned on: its title, channel name, duration, and any visible badges (LIVE, Premiere, Shorts, Mix, Playlist). For mixes and playlists, the first two video titles listed on the card. Also the names and descriptions of your profile's categories.

Where

Only to the provider selected above (), over HTTPS, from the extension's background worker. The request carries no cookies and no referrer.

What is never sent

Your watch history, account, cookies, the page URL, search terms, the video you're watching, view counts, thumbnails, or anything else about you.

What is stored, and where

Everything stays in this browser's extension storage (chrome.storage.local, not synced): your settings, your API key, the decision cache, and today's counters. YouTube's page can't read extension storage, and the content script never gets the key. There is no analytics and no server of ours.
